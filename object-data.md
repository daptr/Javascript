**comment =** piece of text that is not interpreted or executed, denoted with //

**Data =** Message that is printed or logged to the console.

	number = Any number without quotes. ''
	BigInt = Any number bigger then 2⁵³ -1 or smaller then -(2⁵³-1) with n appended to the 	number.
	string = Character(s) wrapped in quotes. '' //also known as text
	boolean = Data type with only 2 possible values.
	null = Intentional absence of a value indicated by the keyword null. //None
	undefined = Absence of a value though it has a different use then null.


**Integer:** Number without decimals.


**Operator:** Apecial character or series of characters that perform a task.

	+ = Adds to a value, can also be used to concatenate strings.
	- = Subtracts from a value.
	* = Multiplies by a value
	/ = Divides by a value.
	% = Finds the remainder after dividing two values.
	** = Returns exponentiation of first value 90990

**Properties =** Property of an object that stores information denoted with . `[OBJECT].[PROPERTY]`

**Methods =** Property of an object that performs an action. `[OBJECT].[METHOD]`

	Math = .Random, .floor(), .ceil()
